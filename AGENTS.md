# Regole del progetto

- Mantieni il codice Python semplice, modulare, leggibile e spiegabile.
- Usa fonti e API ufficiali e aggiornate.
- Non inventare dati, risultati o disponibilità delle API.
- Preserva senza modifiche i formulari ufficiali originali.
- Distingui chiaramente dati osservati, modelli ed euristiche.
- Aggiorna README e test quando cambia una funzione.
- Esegui i test pertinenti prima di dichiarare completato un intervento.
- Non salvare nel repository chiavi API, password o file `.env`.
- Non aggiungere dipendenze o strutture non necessarie.
- Non effettuare commit o push senza una richiesta esplicita.
